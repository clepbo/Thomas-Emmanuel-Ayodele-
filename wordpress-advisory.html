01 — Theme Strategy

The TEA portfolio is a bespoke, hand-coded design. To replicate it faithfully in WordPress, choose one of these approaches:

Option A
Custom Child Theme (Recommended)
Use a minimal blank theme like Underscores (_s) or Blocksy as a parent, then build a child theme that enqueues your custom CSS and JS. This gives full control with zero bloat.
Option B
Page Builder (Bricks Builder)
Bricks Builder outputs clean semantic HTML, supports custom CSS per element, and allows injecting raw JS. It is the closest page builder to hand-coded output and handles dynamic portfolio posts natively.
Option C
Headless WordPress
Use WordPress as a headless CMS (WPGraphQL + Next.js or Astro) and serve the HTML/CSS/JS files directly. Best for performance and design fidelity; requires a developer.
Avoid
Elementor / WPBakery
These builders inject heavy bloat that conflicts with custom animations and cursor behaviour. Avoid for a design this bespoke.

02 — Recommended Plugins

Core Plugins

  • Advanced Custom Fields (ACF) Pro — manage project data, testimonials, journal posts as custom post types with custom fields. Powers the portfolio grid dynamically.
  • WP Rocket — caching and performance optimisation. Critical for keeping animation-heavy pages fast.
  • Smush or ShortPixel — image compression. When real project photos are added, use WebP format for cards.
  • Yoast SEO or RankMath — SEO meta, Open Graph for social sharing of portfolio pages.
  • WPForms or Gravity Forms — contact form with conditional logic for the budget selector and email notifications.
  • CPT UI — register custom post types: tea_project, tea_journal, tea_testimonial.

Optional but Useful

  • GSAP (via CDN) — not a plugin, but enqueue GreenSock in functions.php for timeline-based animations.
  • Lenis (via CDN) — smooth scroll library that replaces native browser scroll with buttery momentum scrolling.
  • SplitType (via CDN) — splits text into characters/words for character-by-character reveal animations on headings.

03 — Animations & Motion

All scroll-reveal animations in the HTML prototype use a lightweight IntersectionObserver. In WordPress, enqueue this in functions.php:

functions.php — Enqueue Scripts

wp_enqueue_script('tea-shared', get_stylesheet_directory_uri().'/shared.js', [], '1.0', true);
wp_enqueue_style('tea-shared', get_stylesheet_directory_uri().'/shared.css', [], '1.0');

Scroll Reveal (.r / .on system)

Add the class r to any element you want to animate in. The shared.js IntersectionObserver watches all .r elements and adds .on when they enter the viewport. Delay variants .d1 through .d5 stagger children.

In Bricks Builder: Add r to the element's Custom CSS Class field. No PHP needed.

GSAP for Advanced Timelines

For the hero heading staggered reveal and the stat counter animation, use GSAP's ScrollTrigger plugin. Enqueue from CDN:

Enqueue GSAP + ScrollTrigger

wp_enqueue_script('gsap', 'https://cdnjs.cloudflare.com/ajax/libs/gsap/3.12.5/gsap.min.js', [], null, true);
wp_enqueue_script('scrolltrigger', 'https://cdnjs.cloudflare.com/ajax/libs/gsap/3.12.5/ScrollTrigger.min.js', ['gsap'], null, true);

Then in your custom JS file, register ScrollTrigger and animate headings:

Hero Title GSAP Animation

gsap.registerPlugin(ScrollTrigger);
gsap.from('.hero-title', {opacity:0, y:40, duration:1.1, ease:'power3.out', delay:0.4});
gsap.from('.hero-desc', {opacity:0, y:24, duration:0.9, ease:'power3.out', delay:0.7});

SplitType for Text Reveals

To animate the large serif headings character by character (as seen on the homepage "Shaping brands that last"):

Character-level reveal

const split = new SplitType('.hero-title', {types:'chars'});
gsap.from(split.chars, {opacity:0, y:60, stagger:0.04, duration:0.8, ease:'power4.out'});

04 — Custom Cursor

The gold dot cursor and trailing ring are built in shared.js. In WordPress, this works out of the box once the script is enqueued. Just ensure the two cursor divs are in every page's HTML:

Add to header.php (or via wp_body_open hook)

<div id="cur"></div>
<div id="cur-ring"></div>

In your theme's header.php, after the opening <body> tag, add the above two divs. The CSS in shared.css handles cursor:none on body and positions both elements via JS mouse tracking.

Note: Set cursor: none !important on *, a, button in your theme's CSS to prevent the default cursor showing over interactive elements that override body styles.

05 — Page Loader

The TEA monogram loader fades out after the page loads. Add this to header.php immediately after the opening <body> tag:

Loader HTML in header.php

<div id="loader">
  <div class="loader-monogram">T<i>EA</i></div>
  <div class="loader-bar-wrap"><div class="loader-bar"></div></div>
  <div class="loader-text">Loading</div>
</div>

The shared.js listens for window.load and adds the class done to #loader, which CSS transitions to opacity:0; visibility:hidden. This works identically in WordPress.

06 — Parallax & Particles

Floating Particle Canvas

The animated gold dust particles on the homepage hero use an HTML5 <canvas> element driven by shared.js's initParticles() function. In WordPress, include the canvas in your hero template part:

In hero template (page-home.php or Bricks widget)

<canvas id="particles" style="position:absolute;inset:0;pointer-events:none;z-index:1"></canvas>

shared.js auto-initialises initParticles('particles') on load. The canvas auto-resizes using a ResizeObserver.

CSS Parallax (Background elements)

The large background glyph text that shifts on scroll uses the data-parallax attribute approach in shared.js. Add data-parallax="0.3" to any element to make it scroll at 30% speed. Works in any WordPress page builder by adding a custom attribute.

07 — Scrolling Marquee

The discipline marquee uses pure CSS @keyframes animation with width:max-content. To make it dynamic in WordPress (editable from the admin), use ACF to create a repeater field marquee_items and loop through it:

Dynamic marquee with ACF repeater

<div class="marquee-outer">
  <div class="marquee-track">
    <?php if(have_rows('marquee_items','option')): while(have_rows('marquee_items','option')): the_row(); ?>
    <span class="marquee-item"><?php the_sub_field('label'); ?></span>
    <?php endwhile; endif; ?>
    <!-- Duplicate for seamless loop -->
  </div>
</div>

Tip: Duplicate the items in PHP (output them twice) to ensure the marquee loops seamlessly, since the CSS animation translates by -50% of the total width.

08 — Contact Form

The contact form uses a custom HTML layout with budget pill selectors and a smooth success animation. In WordPress:

  • Use WPForms Pro — it supports custom CSS classes on fields. Map each field to the corresponding .field div wrapper using WPForms' "CSS Class" option in field settings.
  • For the budget pill buttons: add a hidden WPForms field for budget, then use the custom JS in shared.js's selectBudget() function to update the hidden field's value on pill click.
  • For the success animation: use WPForms' "Confirmation" setting to trigger a custom JS callback instead of a page redirect. Add an event listener to WPForms' wpformsAjaxSubmitSuccess hook:
WPForms success callback

document.addEventListener('wpformsAjaxSubmitSuccess', function() {
  document.getElementById('contactForm').style.opacity = '0';
  setTimeout(() => {
    document.getElementById('contactForm').style.display = 'none';
    document.getElementById('formSuccess').style.display = 'block';
  }, 420);
});

Set the WPForms confirmation type to "Message" with an empty message, so no default success text appears before your custom animation triggers.

09 — Portfolio Grid & Filter

Register a custom post type tea_project using CPT UI or in functions.php. Add ACF fields: project_category, project_year, project_tags, project_thumbnail (image), project_coming_soon (true/false).

Dynamic Grid Query

WP_Query for portfolio grid (page-work.php)

$projects = new WP_Query(['post_type'=>'tea_project', 'posts_per_page'=>-1, 'orderby'=>'menu_order', 'order'=>'ASC']);
while($projects->have_posts()): $projects->the_post();
  $cat = get_field('project_category');
  $coming = get_field('project_coming_soon');
  echo '<a class="project-card '.($coming?'coming-soon':'').'" data-cat="'.$cat.'">...';
endwhile;

Isotope / Native Filter

For the filter bar, use Isotope.js (loaded from CDN) for smooth layout transitions when filtering. Alternatively, the current prototype uses a simple CSS opacity toggle which works without any library — just add data-cat to each card and filter via JS as shown in work.html.

10 — Typography & Fonts

The TEA portfolio uses two Google Fonts: Playfair Display (serif, for all headings and editorial text) and Syne (sans-serif, for UI labels and body copy), plus Syne Mono for metadata and monospace labels.

Enqueue via functions.php using wp_enqueue_style, or use the Google Fonts plugin. For best performance, self-host the fonts using the OMGF (Optimize My Google Fonts) plugin — this eliminates the external DNS lookup and improves Core Web Vitals.

functions.php font enqueue

wp_enqueue_style('tea-fonts', 'https://fonts.googleapis.com/css2?family=Playfair+Display:ital,wght@0,400;0,700;1,400&family=Syne:wght@300;400;500;700&family=Syne+Mono&display=swap', [], null);

11 — Performance Tips

  • Defer non-critical JS — add defer to shared.js and GSAP in your wp_enqueue_script call via the $in_footer = true argument.
  • Replace SVG artwork with real photos — when actual project photography is available, use <img> with loading="lazy" and WebP format. The SVG placeholders are designed to be dropped in place.
  • Avoid animation on mobile — add a media query: @media (prefers-reduced-motion: reduce) { .r { transition: none; opacity: 1; transform: none; } }. Also conditionally disable the particle canvas on mobile using JS: if(window.innerWidth < 768) return; in initParticles.
  • WP Rocket settings — enable "Delay JavaScript Execution", exclude shared.js and GSAP from delay. Enable CSS minification but exclude shared.css to avoid selector mangling.
  • Disable unused animations on pages — the particle canvas, scramble effect, and magnetic buttons are optional. Conditionally load them only on the homepage using is_front_page() in a PHP check before enqueuing the relevant JS block.
  • Core Web Vitals — the custom cursor can cause LCP issues if the body cursor:none style is applied before the font loads. Wrap cursor init in a DOMContentLoaded listener, not just inline.

  • Custom Post Types: CPT UI — tea_project, tea_journal
  • Custom Fields: Advanced Custom Fields (ACF) Pro

  • Smooth Scroll: Lenis.js (CDN)
  • Portfolio Filter: Isotope.js or native JS data-cat filter
  • Fonts: Google Fonts via OMGF (self-hosted)
  • Performance: WP Rocket + Smush/ShortPixel
  • SEO: RankMath Pro
